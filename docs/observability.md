# Observability

`GET /operations` returns queue states, admission saturation, 60-second success throughput, execution duration average/P50/P95/P99, mean queue wait, and bounded recent workers/events. `/metrics` emits Prometheus text format 0.0.4 (`text/plain; version=0.0.4`) under client authentication, with a `# TYPE` line for every metric family. With `REQUIRE_TLS=true` a plain-HTTP scrape gets 426, so scrape through TLS. Counters derive from durable events, so coordinator restart does not reset them. Removing history would reset derived totals and must be accounted for by operators. Every coordinator reports the same global counters, so scrape one coordinator (or de-duplicate) rather than summing across several.

Execution duration is finish minus start, and queue wait is attempt creation minus original job creation (including earlier retry history for later attempts). Both cover attempts finished in the last hour (`latency_window_seconds` in the response), so each poll stays cheap as history grows. These are not identical to end-to-end latency, which the benchmark records separately. `/workers` and the worker list in `/operations` are bounded at 200; global state counts are queried independently. DEAD workers are counted in `greyqueue_workers{state="DEAD"}` but get no per-worker utilization or heartbeat series.

Worker logs include job_id, worker_id, attempt_id and fence on `started`, `finished` and `lease_fenced` events. Request logs include a generated request_id, method, path, status and duration; credentials and payloads are not logged, and database errors are logged without bound parameters. System events preserve worker registration, re-registration, suspicion/death, recovery to HEALTHY, drain and lease expiry. Job events preserve state transitions.

Dashboard: `/dashboard`. It uses same-origin fetch, textContent for untrusted values, no local/session storage of tokens, no external chart scripts, and a strict script policy. Panels show explicit empty, stale and disconnected states; disconnecting clears displayed results. Desktop/mobile browser tests cover connection, submission, completion, inspection, the complete state filter, empty states, layout and disconnect.

Example Prometheus configuration and an importable Grafana dashboard are under `monitoring/`. Supply the client token through a local secret file; never commit it.
